## 🚀 Ringkasan Eksekutif & Pencapaian Utama

Proyek **BelajarKompre** dirancang sebagai sistem persiapan belajar mandiri dan ujian komprehensif terlengkap bagi mahasiswa S1 Informatika Undip. Seluruh arsip dari **DMW (Drive Mahasiswa) HMIF Undip** telah diunduh, disortir, dan dianalisis secara mendalam tanpa halusinasi, menghasilkan tiga lapis aset pengetahuan utama:

1. **🌟 8 Berkas Acuan Sintesis Semester (`semester1.md` s.d. `semester8.md`):**
   * Berada langsung di root direktori dan disinkronkan ke folder semester masing-masing (`RANGKUMAN_SEMESTER_X.md`).
   * Mengintegrasikan seluruh mata kuliah dalam satu semester menjadi satu narasi pembelajaran terpadu, peta relasi antarmatkul, formula penting (KaTeX), dan checklist persiapan ujian komprehensif.
2. **📚 88 Berkas Rangkuman & Contoh Soal Komprehensif (100% Selesai):**
   * Berada di folder: [`RANGKUMAN_DAN_CONTOH_SOAL/`](./RANGKUMAN_DAN_CONTOH_SOAL/)
   * Terdiri dari **44 Berkas `RANGKUMAN_MATERI.md`**: Grand View mata kuliah, diagram alir Mermaid, peta silabus 14 pertemuan (Pra-UTS & Pasca-UTS), dan rumus/konsep inti slide perkuliahan.
   * Terdiri dari **44 Berkas `CONTOH_SOAL_DAN_PEMBAHASAN.md`**: Bank contoh soal riil UTS dan UAS, solusi langkah demi langkah (*step-by-step*), jebakan ujian (*exam traps*), dan simulasi pertanyaan ujian lisan komprehensif (*oral defense*).
3. **📦 1.436 Berkas Arsip Mentah Asli (~2,85 GB):**
   * Terorganisir rapi di folder semester: [`01_Semester_1/`](./01_Semester_1/) hingga [`08_Semester_8/`](./08_Semester_8/).
   * Memuat seluruh slide dosen, modul praktikum lab, buku panduan resmi, dan arsip lembar soal ujian HMIF dari tahun ke tahun.
4. **💻 Portal Dashboard Interaktif (`index.html`):**
   * Dashboard berbasis web modern (TailwindCSS) dengan rendering formula matematika KaTeX yang presisi, diagram alur Mermaid, syntax highlighting code, pencarian instan, filter semester/bidang, dan pembaca modal (*in-app reader*).

## 🎯 Panduan Membuka & Belajar

1. **Menggunakan Portal Web:**
   * Buka berkas [`index.html`](./index.html) di browser atau kunjungi versi online [khairys.github.io/BelajarKompre/](https://khairys.github.io/BelajarKompre/).
   * Klik tombol **✨ Rangkuman Semester (1-8)** di navbar atau banner interaktif untuk membaca sintesis satu semester sekaligus.
   * Gunakan filter dan search bar untuk mencari topik spesifik, lalu klik **📖 Rangkuman** atau **📝 Bank Soal** per mata kuliah.
2. **Membaca via Markdown Editor / AI Agent:**
   * Buka `semester1.md` s.d. `semester8.md` untuk memahami gambaran besar, relasi konsep, dan persiapan ujian semester.
   * Buka `RANGKUMAN_MATERI.md` dan `CONTOH_SOAL_DAN_PEMBAHASAN.md` pada folder mata kuliah terkait untuk pendalaman mendalam tingkat silabus dan bank soal.
