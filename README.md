## 🚀 Ringkasan Eksekutif & Pencapaian Utama

Proyek **BelajarKompre** dirancang sebagai sistem persiapan belajar mandiri dan ujian komprehensif terlengkap bagi mahasiswa S1 Informatika Undip. Seluruh arsip dari **DMW (Drive Mahasiswa) HMIF Undip** telah diunduh, disortir, dan dianalisis secara mendalam tanpa halusinasi, menghasilkan dua aset utama:

1. **88 Berkas Rangkuman & Contoh Soal Komprehensif (100% Selesai):**
   * Berada di folder: [`RANGKUMAN_DAN_CONTOH_SOAL/`](./RANGKUMAN_DAN_CONTOH_SOAL/)
   * Terdiri dari **44 Berkas `RANGKUMAN_MATERI.md`**: Grand View mata kuliah, diagram alir Mermaid, peta silabus 14 pertemuan (Pra-UTS & Pasca-UTS), dan rumus/konsep inti slide asli perkuliahan.
   * Terdiri dari **44 Berkas `CONTOH_SOAL_DAN_PEMBAHASAN.md`**: Bank contoh soal riil UTS dan UAS, solusi langkah demi langkah (*step-by-step*), jebakan ujian (*exam traps*), dan simulasi pertanyaan ujian lisan komprehensif (*oral defense*).
2. **1.436 Berkas Arsip Mentah Asli (~2,85 GB):**
   * Terorganisir rapi di folder semester: [`01_Semester_1/`](./01_Semester_1/) hingga [`08_Semester_8/`](./08_Semester_8/).
   * Memuat seluruh slide dosen, modul praktikum lab, buku panduan resmi, dan arsip lembar soal ujian HMIF dari tahun ke tahun.
3. **Portal Dashboard Interaktif (`index.html`):**
   * Dashboard berbasis web modern (TailwindCSS) dengan fitur pencarian instan, filter semester, metrik statistik, dan akses langsung sekali klik (*one-click view*) ke setiap berkas rangkuman dan soal.

## 🎯 Panduan Membuka & Belajar

1. **Menggunakan Portal Web:**
   * Buka berkas [`index.html`](./index.html) menggunakan peramban web (Google Chrome, Firefox, Edge, atau Safari).
   * Gunakan bilah pencarian atau filter semester untuk menemukan mata kuliah yang diinginkan.
   * Klik tombol **📖 Rangkuman Materi** atau **📝 Contoh Soal & Kompre** untuk langsung membaca kajian materi.
2. **Membaca via Markdown Editor / VS Code:**
   * Masuk ke folder `RANGKUMAN_DAN_CONTOH_SOAL/`.
   * Buka berkas `RANGKUMAN_MATERI.md` untuk menguasai peta konsep dan alur silabus 14 pertemuan.
   * Buka berkas `CONTOH_SOAL_DAN_PEMBAHASAN.md` untuk menguji pemahaman dengan latihan soal berbobot tinggi dan simulasi pertanyaan sidang penguji komprehensif.
